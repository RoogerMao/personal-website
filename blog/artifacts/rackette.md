An interpreter for Rackette, a subset of the Racket programming language. Our
implementation identified keywords and values from a string of tokens,
evaluated subsequent expressions, and returned output to the user. Supported
Racket functions include: conditionals (`cond`), boolean logic (`and`, `or`),
`lambda` expressions, and subenvironments (`let` expressions).
