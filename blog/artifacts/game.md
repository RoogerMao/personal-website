This project consisted of two parts: 1) a game managing module for
Toads and Frogs, a combinatorial game, and 2) a minimax algorithm and tree
implementation to store future game states. Functionality requirements included
generating future game states, validating potential moves, and designing a
terminal-based UI to prompt user input.
